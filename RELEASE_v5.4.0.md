Описание релиза v5.4.0
Выпуск v5.4.0: Удаленная конфигурация, гибридный Watchdog-цикл, жесткий контроль батареи и новая иконка

Защита от замерзания корутин (Watchdog + Hybrid Loop)
На агрессивных прошивках (TECNO/Infinix/HiOS 15+) стандартные корутины и таймеры `delay()` могли замораживаться операционной системой при переходе устройства в Deep Sleep, несмотря на наличие WakeLock.
Теперь в приложении реализован гибридный цикл сканирования. При включении экспериментального режима (`experimental_alarm_watchdog`) приложение комбинирует стандартный `Thread.sleep()` и аппаратный будильник `AlarmManager.setExactAndAllowWhileIdle()`. Этот будильник аппаратно выводит процессор из спячки каждую минуту и принудительно запускает сбор данных. Для этого в манифест добавлено разрешение `SCHEDULE_EXACT_ALARM`.

Жесткий контроль белого списка батареи (Doze Whitelist)
В прошлой версии приложение только просило добавить его в белый список энергосбережения (показывало in-app диалог). Однако пользователи могли проигнорировать просьбу, что приводило к потере данных в фоновом режиме.
Теперь приложение жестко блокирует старт сканирования, если не находится в белых списках. При попытке запустить сбор данных появляется системный диалог с требованием отключить оптимизацию. Без этого приложение работать не будет — это гарантирует сохранность данных на ходу.

Удаленная конфигурация (Feature Toggle)
Для быстрого включения и отключения экспериментальных функций в приложении реализован сервис Feature Toggle.
Добавлен `RemoteConfigManager.kt`, который при старте приложения загружает настройки с удаленного сервера (`http://159.194.216.130:3100/api/v1/config`). Благодаря этому мы можем управлять поведением приложения (например, включать или выключать гибридный Watchdog-цикл) на лету, не пересобирая APK. Конфигурация кэшируется локально, поэтому приложение остается устойчивым к работе без интернета.

Новая иконка приложения
Приложение получило обновленный визуальный стиль: внедрена новая современная векторная иконка приложения с оптимизированным масштабом отображения для всех типов лаунчеров.
