# Релиз 5.4.0 (Обход блокировок и Feature Toggle)

В этой версии мы полностью решили проблему засыпания приложения при сборе данных с радиоэфира на телефонах с агрессивной политикой энергосбережения (TECNO, Infinix, HiOS 15+).

## 🚀 Основные нововведения

1. **Feature Toggle (Удаленное управление фичами)**
   Мы добавили `RemoteConfigManager` для динамического включения и отключения новых экспериментальных алгоритмов без необходимости пересобирать APK. 
   
2. **Аппаратный будильник (Watchdog + Hybrid Loop)**
   Корутины и `delay()`, на которых был построен цикл сканирования, замораживались ОС в фоновом режиме (Deep Sleep). Теперь, если включен тоггл `experimental_alarm_watchdog`, приложение использует аппаратный `AlarmManager.setExactAndAllowWhileIdle()`, гарантированно «будящий» процессор каждую минуту для выполнения сканирования.
   
3. **Строгий контроль батареи (Doze Whitelist)**
   Ранее приложение просило добавить его в белый список энергосбережения, но пользователи могли проигнорировать этот шаг. Из-за этого сканер работал некорректно. Теперь приложение аппаратно блокирует старт сбора данных до тех пор, пока пользователь не отключит оптимизацию батареи для данного приложения через системные настройки.

## 🛠 Технические изменения
- **API**: Добавлен клиент для Feature Toggle API (`http://159.194.216.130:3100`).
- **Разрешения**: Добавлено разрешение `SCHEDULE_EXACT_ALARM` для корректной работы будильника в Android 12+.
- **Логика циклов**: Гибридный Thread + Watchdog-паттерн вместо чистых корутин.
